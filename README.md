# <b>Features</b>
### <i>Pick your poison</i>
My dotfiles contain configs for both **[Waybar](https://github.com/Alexays/Waybar)** and **[Quickshell](https://quickshell.org/)**. Depending on whether you want a classic, reliable status bar or a fully custom, animated Qt/QML desktop shell, you can pick whatever fits your workflow best!

### <i>Theme switcher</i>
Includes a fully functional theme switcher that seamlessly propagates color schemes and styles across your entire desktop ecosystem:
* **GTK Apps:** Synchronizes color themes and palettes.
* **Qt Apps:** Keeps your Qt-based applications matching in style.
* **Terminal:** Instantly updates your terminal color schemes.
* **Quickshell Configs:** Dynamically hot-reloads your Quickshell widgets and bars to match the new look on the fly.

### <i>Dynamic island style media player</i>

Centered right on the Quickshell bar is a custom, interactive pill-shaped dynamic island inspired by modern mobile UI design. It adapts seamlessly to your desktop activity:
* **Idle State:** Displays the current time accompanied by a smooth, live-updating analog clock face.
* **Media State:** Automatically detects active playback and fluidly expands into a rich media player complete with track details and a real-time audio visualizer.
* **Hover State:** Shows calender.

### <i>Interactive Wallpaper Switcher</i>
Built directly into the Quickshell environment, this widget lets you browse and switch your desktop backgrounds on the fly. 
* **Seamless `awww` Integration:** Blazingly fast wallpaper switching powered natively by the `awww` daemon.
* **Instant Visual Preview:** Displays thumbnails or a quick selection menu right from your bar or shell overlay.

## Dependencies

```bash
kitty matuwall cava hypland waybar rofi fastfetch nvim zsh dunst mpv hyprlock oh-my-zsh quickshell hyprsunset
```

<br><br>

> [!NOTE]
> * Dotfiles are managed using GNU Stow.
> * There is no installation script atm, you just need to copy each config directory to <code>~/.config/</code>
> * For hyprlock to work properly, you need to have <code>Anurati</code> font installed.
> * Media Player - mpv
> * Music Player - amberol
> * Neovim - NvChad
